# Diffraction Grating Simulator

An interactive web-based simulation of diffraction grating that visualizes spectral dispersion and angular deviation in real time.

## 🚀 Features
- Adjustable wavelength (λ), spectral order (m), and grating density (N)
- Real-time calculation using the formula: d · sinθ = m · λ
- Dynamic canvas-based visualization of diffraction patterns
- Mercury spectral line comparison with deviation analysis
- Elegant and responsive UI design

## 🧠 Concepts Used
- Diffraction Grating Physics
- Trigonometry (sin, inverse sin)
- Real-time rendering using Canvas API

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 💡 How It Works
The simulator calculates diffraction angles using the equation:

d · sinθ = m · λ

Where:
- d = grating spacing
- θ = diffraction angle
- m = order of spectrum
- λ = wavelength
